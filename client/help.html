FILE2P HELP

File2P transfers files directly between browsers. The server helps both devices connect; it does not store your file.

What is peer-to-peer transfer?

Peer-to-peer means the sender browser talks directly to the receiver browser. File2P uses WebRTC data channels for this. The file is streamed in chunks from the sender tab to the receiver tab.

What does the server do?

The server is only a signaling server. It receives temporary connection messages, the transfer code, file name, and file size. It does not receive or store the file contents.

Why is same WiFi faster?

When both devices are on the same network, WebRTC can usually send traffic through the local router. That avoids the internet path and can be much faster than your ISP or mobile data speed.

Why is mobile data slower?

Mobile networks often use strict NAT, carrier-grade NAT, and unstable UDP routing. WebRTC may still connect, but throughput can drop hard. Uploading from a phone on mobile data is usually the weakest case.

What should I do on phones?

  • Keep the sender tab open until the transfer completes.
  • After sharing the link, return to the sender tab.
  • Do not lock the sender device during transfer.
  • If mobile data stalls, put both devices on the same WiFi.

Can I close or reload the page?

Not during transfer. The sender tab is the source of the file, and the receiver tab is writing the file. Reloading either side stops the active transfer.

Why did the transfer stop?

  • The sender tab was closed, reloaded, or backgrounded by the device.
  • The network changed during transfer.
  • The browser paused the tab to save battery.
  • The mobile carrier degraded or blocked the WebRTC path.

Are files stored in the cloud?

No. There is no upload storage. If the sender leaves, the file is gone from the transfer. The receiver can only download while the sender is online.

Which browsers work best?

Chromium browsers generally handle large downloads better because they can stream directly to disk in some cases. Firefox and Safari work, but may keep more received data in memory until the download finishes.

Can I send folders?

Not directly. Compress the folder into a zip file first, then send the zip. File2P transfers one selected file at a time.
